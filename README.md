# Chemistry Quiz (Vite)

## Run locally

1. Install Node.js LTS.
2. In this folder run `npm install`.
3. Run `npm run dev` and open the local URL printed by Vite.
4. Before publishing, run `npm run build`; Vite writes the website to `dist/`.

## Code layout

- `index.html`: page structure
- `style.css`: styling
- `src/app.js`: quiz logic and answer checking
- `src/data/constants.js`: shared digit/symbol constants
- `src/data/ions.js`: cations, anions, polyatomic ions
- `src/data/precipitates.js`: precipitation questions and color aliases
- `src/data/molar.js`: molar-mass question data
- `src/data/elements.js`: periodic-table element data
- `src/main.js`: JavaScript entry point
- `vite.config.js`: Vite settings
- `.github/workflows/deploy.yml`: GitHub Pages deployment workflow

The app's Persian interface and existing quiz behavior are retained; the original data is separated into topic-specific modules so it is easier to edit.

## GitHub Pages

Commit and push all project files, including `package-lock.json` generated by `npm install`. In the repository, go to **Settings → Pages** and choose **GitHub Actions** as the build/deployment source. The workflow deploys on pushes to `main`.
